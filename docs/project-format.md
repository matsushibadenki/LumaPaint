# LumaPaint v1保存形式

`.lumapaint`はUTF-8 JSON。現行の固定960×640・描画レイヤー・SVG参照元保持モデルの形式で、設計仕様の将来のタイル／処理グラフコンテナとは区別する。

```json
{"format":"LumaPaint","version":1,"width":960,"height":640,"layerVisible":true,"strokes":[{"brush":{"size":16,"color":[32,32,32]},"points":[{"x":20,"y":40}]}],"svgLayers":[{"id":"svg-layer-1","name":"logo","visible":true,"source":"<svg>…</svg>"}]}
```

- 色はsRGBの整数RGB。ブラシ径1〜512px、硬さ0〜1、座標はドキュメントのpx単位。硬さを持たない旧ファイルは1として読み込む。
- SVGは元のXMLを独立レイヤーとして保持し、縦横比を保って960×640の中央へ収める。1ファイル4MiB、1作品16レイヤー・合計6MiBを上限とする。
- 最大8MiB、全ストローク合計65,536点。空のストローク、非有限値、絶対値100,000以上の座標、不正ブラシ、未知のフィールド・形式・バージョン・寸法は拒否。
- 開く操作は検査完了後にドキュメントを置換。Redo履歴は破棄し、読み込んだ各ストロークはUndoできる。
- 保存は同一ディレクトリで一時ファイルを作成し、書き込み・sync_all後にpersistで置換。失敗時に保存済み表示へ進めない。
- 保存済みrevisionとの比較で未保存状態を判定する。Undoで同じ画像に戻っても保守的に未保存とする。
- ファイルパスはネイティブダイアログで選択しRust側だけで保持する。UIから任意のパスをIPCに渡さない。

## 制約

手動保存のファイルI/Oとダイアログは現在macOSホストのメインスレッドで実行する。復旧用コピーのJSON化・ファイルI/Oは専用ワーカーで行う。上限内の小規模ドキュメントを対象とし、大型化時はスナップショットとバックグラウンドI/Oへ移す。
保存形式とI/Oは他OSと共有可能だが、他OSのネイティブ編集ホストは未実装。
復旧用コピーの自動保存・復旧は実装済み（[仕様](recovery.md)）。手動保存ファイルの外部編集競合検出は未実装。アプリの終了メニュー／⌘Qとウィンドウを閉じる操作には確認を入れるが、Dockからの終了・OSログアウト・強制終了は保証対象外。
ファイル置換の原子性はOS／ファイルシステムに依存する。ディレクトリエントリの電源断耐性やネットワークドライブは未検証。

参照：[rfdのネイティブダイアログ](https://docs.rs/rfd/0.17.2/rfd/)


## 編集可能な文字

ベクターオブジェクトの`kind: "text"`と`text`へ本文、フォントファミリー、文字サイズ、行送り比率、太字・斜体、字間、水平／垂直比率、ベースラインシフト、回転、下線・打ち消し線、段落揃え、枠幅、左右／先頭インデント、段落前後のアキを保存する。長さは作品ピクセル、字間は1/1000 em、回転は度。UIのpt表示は解像度に応じて換算する。旧ファイルに追加の書式フィールドがなければ既定値で読み込む。任意フォント名はSVG属性へ出力する際にXMLエスケープする。

文字は最大4096文字・64行。非有限値、不正な比率・寸法・インデントは文書を変更する前に拒否する。フォントファイルは埋め込まないため、別端末で未導入のフォントは代替フォントへ置き換わる。

文字の`text.runs`はUTF-16の半開区間`start`／`end`と`style`の配列。`style`はfontFamily、fontSize、bold、italic、tracking、baselineShift、underline、strikethrough、RGB colorを保持する。範囲は昇順かつ重複なし、本文内に限定し、サロゲートペアの途中を境界にできない。最大4096範囲。隣接する同一書式は統合し、空白区間および旧ファイルのruns省略時はオブジェクトの基本書式と塗り色を継承する。段落設定と枠の変形は従来どおり共通。SVGへは文字列を分割したtspanとして出力するため、保存・再読込・書き出しにも異なる文字書式が反映される。

`text.softBreaks`はmacOSのインライン編集・文字パネル変更時の組版が枠幅に応じて付けた視覚行の開始位置（UTF-16オフセット）。本文に改行文字を挿入せず、`runs`の文字位置を変えない。昇順・重複なし・文字境界のみとし、明示的な改行の前後には置かない。旧作品では省略を空配列として読み込む。SVGは保存済みの視覚行で再描画するため、別端末でフォントが置換された場合、折り返し位置がその端末の自然な位置と異なる可能性がある。再組版と正確な字形境界は後続工程とする。
