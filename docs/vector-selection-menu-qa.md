## Vector layer rasterization — 2026-10-22

LayerList exposes a context menu only for vector layers. The command targets the right-clicked ID; it does not rely on whichever layer was previously selected. The entry supports Japanese, English and Simplified Chinese, Shift+F10/ContextMenu, Escape and outside-click dismissal. Locked layers are disabled. Busy state prevents duplicate launches; native failure remains visible and permits retry. Rename inputs retain their text-edit context menu. The popup fits within the viewport and leaves no empty leading check column.

Rust prepares a job from a standard document, rasterizes only the layer's SVG content at document pixel dimensions using the existing GPU-preferred vector renderer/fallback, encodes a premultiplied-alpha-correct PNG, then commits an in-place replacement. Pixel data stays native. Layer identity/order, folder membership, visibility/opacity, masks and effects remain attached and are not baked twice. The pixel layer keeps no vector objects; Undo restores vector content and Redo restores raster content. Project save/reload retains the result. Commit rejects changed document identity, revision, selected target/objects, source or active strokes. Existing 16MP raster and SVG byte budgets apply before mutation. This converts retained SVG content; animated/3D preview baking is not claimed.
