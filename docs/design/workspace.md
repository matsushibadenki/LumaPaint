# 編集ワークスペース

Adobe Photoshopの[ワークスペース構成](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html)を参考に、作業対象を中央に、頻繁な操作をその周囲に配置する。

- 上部：アプリアイコン、11分類のプルダウンメニュー、パネル表示と選択ツールの設定。
- 左：ツール列。上部の2×2アイコンでペイント／ベクター／レイアウト／アニメーションを直接選択し、モードに応じたツールを表示する。
- 中央：ドキュメントタブ、キャンバス、ズームと状態。
- 右：ブラシのプロパティ、ドキュメント寸法、レイヤーを切り替えるタブ式ドック。タブはドラッグで並べ替えられ、選択と順序を端末内に保持する。

中立色を中心とし、選択状態のみ青で示す。OS標準フォントと細い区切り線を使い、作品に視線が向く密度にする。
生成した配置検討画像は `workspace-concept.png`。メニュー内の未実装項目は「準備中」と表示し無効化する。
ファイル、編集、イメージ、レイヤー、書式、選択範囲、フィルター、表示、プラグイン、ウインドウ、ヘルプを配置する。
デスクトップではGPUキャンバスの上に表示できるOS標準のポップアップメニューを使い、ブラウザではキーボード操作に対応したHTMLメニューを使う。
文字ロゴは置かず、ファイルメニューの左にアプリアイコン、メニュー列の右端にパネル開閉ボタンを同じ1行で配置する。アイコンのメニューから設定画面を開き、一般タブで言語、アピアランスタブで外観を変更する。
画面幅720px以下はパネルとキャンバスを切替表示し、ネイティブ描画の上にHTMLパネルを重ねない。

## レイアウトの文字

「文字」ツール（T）でキャンバスをクリックすると、その場所で直接入力できる。既存の文字は文字ツールでクリック、またはベクター選択でダブルクリックして編集する。macOSのNSTextViewがカーソル・範囲選択・IME・改行・コピー／貼り付けを扱う。⌘Enterまたは文字パネルの「確定」で文書へ反映し、Esc／「取消」で元に戻す。入力中は対象の文字だけをプレビューから除き、他のレイヤーとGPUキャッシュは維持する。入力中の変更は確定時に1回のUndoとして記録する。空の本文を確定した場合は編集を取り消す。

右側の「文字」タブは他のプロパティタブと同様に並べ替え可能。「文字」「段落」「OpenType」のセクションを参考画像のように積み重ね、フォントとスタイルを全幅、数値を2列で配置する。インストール済みフォント、文字サイズ・行送り（pt）、水平／垂直比率、字間、文字色、ベースラインシフト、回転、太字・斜体・下線・打ち消し線、左／中央／右揃え、枠幅、左右／先頭インデント、段落前後のアキを文書に保存する。ptと作品ピクセルは文書の解像度で換算する。編集中のパネル変更は同じ編集セッションへまとめる。

文字の編集中は選択した1文字または範囲へフォント・サイズ・色・太字・斜体・字間・ベースライン・下線・打ち消し線を適用する。選択が空なら次に入力する文字へ適用し、複数の書式がある項目は「混在」と表示する。編集中でない場合はボックス全体へ指定項目のみを適用し、ほかの混在書式を保持する。段落設定、縦横比率、回転はボックス全体へ適用する。横書き・手動改行に対応。自動折り返し、禁則処理、縦書き、任意OpenType機能、フォント埋め込みは後続対応。未実装のOpenTypeボタンは無効にしてその旨を明記する。選択境界はテキスト枠から求めた概算で、AppKitとSVGの字形処理による差は今後の共通組版エンジンで縮小する。
