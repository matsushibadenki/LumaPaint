# 通常移動の差分処理・初回測定（2026-10-05）

[Done] RustコアのRelease測定と、単色ベジェのMetal GPU回帰テスト。

[Next] SVGソースを遅延生成する共有Scene、アプリ全体の入力遅延・GPU時間・メモリ計測、文字・線・グラデーション・透明度・クリップを含む60秒×5回の測定。

環境：この開発端末、macOS 27.0.1、Rust 1.98.1。RustコアはRelease、画素比較のMetalテストはdebug。コア測定に画面解像度・GPUは関与しない。既存アプリとの比較測定は行っておらず、速度向上倍率や60／120fps達成を示す値ではない。

20回ウォームアップ後、1秒×3回。矩形1,000／4,096個、変更対象1個。保存・再読込はメモリ内のDocumentState JSONの10回測定で、ファイルのディスク書き込みや復旧処理を含まない。

| 個数 | 操作 | p95範囲（µs） | p99範囲（µs） |
| --- | --- | ---: | ---: |
| 1000 | 移動 | 7.375–7.625 | 7.459–12.125 |
| 1000 | Undo | 5.791–6.042 | 6.000–9.084 |
| 1000 | Redo | 5.875–6.083 | 6.083–9.375 |
| 4096 | 移動 | 24.792–24.833 | 25.166–26.208 |
| 4096 | Undo | 22.959–23.042 | 23.292–23.375 |
| 4096 | Redo | 23.042–23.083 | 23.333–23.542 |

全レイヤー履歴複製・全SVG生成・ウォーム状態のオブジェクトID全走査はゼロ。1個分の変形/bounds履歴は両方とも80バイト。選択ID、Vecの容量、allocator、文書全体やキャッシュのメモリは別で、この80バイトに含まない。

一方、数値の桁数変更時のSVGソースの推定再配置は、1,000個で365,958バイト、4,096個で1,505,581バイトだった。**履歴の保持量は一定になったが、編集全体のコピー量が総数に依存しないという合格条件は未達**。通常移動で全SVGのシリアライズを省けた段階であり、文字列操作を熱い経路から外す必要がある。

GPU回帰では静止時の全ID収集・SVG生成・BVH構築/refit・geometry生成・作品バッファ転送がゼロ。1個移動でgeometryを再利用しBVHを1葉refit、同じGPUバックエンドの全再描画とRGBA完全一致、Undo/Redo後も元の／移動後の画素と完全一致を確認。試験は単色ベジェであり、全描画対象の保証に拡大しない。

## 固定長スロット導入後の追加測定

[Done] 同じコア用手順（20回ウォームアップ、1秒×3回）で再測定。1,000／4,096個とも、1個移動の履歴80バイト、今回の矩形のSVG更新45バイト、ソース検索0バイト、推定再配置0バイト、全SVG生成0、全レイヤー履歴0。上記の総数に比例する末尾再配置はこの対応経路で解消した。45バイトはこの行列の長さであり、全種類の行列で同じ値とは限らない。アプリ全体のコピー量やfpsを保証しない。

| 個数 | 操作 | p95範囲（µs） | p99範囲（µs） |
| --- | --- | ---: | ---: |
| 1000 | 移動 | 2.041–2.125 | 2.084–3.375 |
| 1000 | Undo | 0.584–0.666 | 0.833–0.917 |
| 1000 | Redo | 0.667–0.709 | 0.750–1.083 |
| 4096 | 移動 | 2.292 | 2.375–2.541 |
| 4096 | Undo | 0.625 | 0.833–0.834 |
| 4096 | Redo | 0.708 | 0.750–0.791 |

保持画像キャッシュの本番更新処理を使ったMetal回帰では、CPUアップロードとSkia共有テクスチャの双方で移動・Undo/Redoが成功。各更新はJournal対象1個、従来複製対象0個、SVGコピー0バイト、描画位置uniform16バイト。テクスチャを再uploadせず、半透明とアートボード外の表示を検証。文字・パスの保持領域が複製されないことは多言語テキストを含む単体テストでも確認した。

## 再実行

```sh
cargo run --release -p lumapaint-core --example bench_translation -- --seconds 60 --runs 5
cargo test --workspace gpu_native_cubic_matches_fill_and_reuses_resident_geometry -- --ignored --nocapture
```
