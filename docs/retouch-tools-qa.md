# Retouch brushes QA — 2026-10-06

[Done] Paint workspace groups Blur, Sharpen and Smudge in one tool menu. U selects Blur; Shift+U cycles the group. Brushes share diameter/hardness and expose Strength, Sample All Layers, pressure size and pressure strength. Sharpen has Protect Detail; Smudge has Finger Painting, with Option at stroke start enabling foreground seeding temporarily. Settings-dialog edits commit on Apply; toolbar settings update immediately. English, Japanese and Simplified Chinese are included. Native brush-outline cursors follow the shared diameter/zoom settings.

[Done] Local blur uses a weighted 3×3 premultiplied-RGBA kernel. Sharpen uses the local unsharp residual, preserves alpha and optionally limits residual magnitude. Smudge advects the previous dab's pixel neighborhood toward the drag direction; Finger Painting seeds the first footprint with foreground color. Each dab reads an immutable source patch, so results do not depend on destination iteration order. Selection masks restrict destination edits while source neighborhoods remain available outside the selection. GPU compute handles patches with at least 4,096 affected pixels; smaller patches use CPU to avoid dispatch/readback overhead. Unavailable/failed GPU processing falls back to the same CPU kernel. This is not Adobe's proprietary filter implementation or a measured performance claim.

[Done] Shared Rust pixel worker captures every pointer sample and publishes coalesced dirty tile previews. Full pixels and source sampling remain in Rust. Pending strokes do not mutate the live document; release validates target/revision and commits one pixel edit. Undo/Redo restore pixel results. Zero strength and byte-identical output do not create history. Base/background and image-backed pixel targets are supported; editable-target checks reject locked, alpha-locked, hidden and vector layers. All Layers samples the visible composite and writes to the selected target only. Existing tile-backed read-only documents retain their editing restrictions.

Verification: 649 workspace tests pass. New tests cover blur/sharpen edge contrast, alpha preservation, smudge transport, foreground seeding, transparent pixels, selection clipping, zero pressure/strength, invalid input and native pointer commit/Undo/Redo for all three tools. Hardware GPU/CPU comparisons pass for all three kernels, alpha and foreground seeding (within one byte of rounding). Three tools × three languages were checked with bundled Playwright/Chrome, including numeric settings, option toggles and menu selection. Japanese Smudge settings were visually inspected after shortening help text into meaningful lines. Browser plugin unavailable; temporary fixtures/server removed. TypeScript, Clippy (warnings denied), formatting, architecture boundaries and diff checks pass. macOS debug app build succeeds (142.78 MiB). Physical-device manual testing and long-stroke latency benchmarks were not performed.
