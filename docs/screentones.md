# スクリーントーン / Screentones / 网点纸

## 操作

インスペクターの網点アイコンから「スクリーントーン」を開く。分類とデザインを選び、数値を設定する。

- **新規トーンレイヤー**：現在の選択範囲をベクター形状として保存し、編集可能なトーン設定付きの塗りレイヤーを作成する。選択範囲がなければ原稿全体。通常文書で使用できる。複合選択は既存のパス演算エンジンで処理する。
- **選択レイヤーに適用**：描画済み領域のアルファをマスクとして使用する。元の色やピクセルは保持し、数値の変更後に適用する。通常文書とタイル文書に対応する。
- **トーンを解除**：トーン設定だけを解除し、他の色調補正は保持する。レイヤーエフェクトの全体スイッチを切るとトーンも一時的に無効になる。
- ホワイトは白インク、カラーは指定色の単色インク。コピーは元画像の輝度を濃度へ変換する。転写はかすれ・粒状感の手続き生成で、外部画像の転写や市販トーン素材の互換インポートではない。
- パネルは他のインスペクターパネルと同じ操作でドッキング／フローティングできる。UIは日本語・英語・简体中文。

## 分類とデザイン

| 分類 | 4デザイン |
|---|---|
| アミ（網点） | 円・四角・菱形・楕円 |
| グラデーション | 線形・円形・反射・波形 |
| 万線 | 直線・波線・破線・二重線 |
| 柄 | 格子・菱形格子・花・市松 |
| CG | ウェーブ・干渉・同心波・雲状 |
| 砂目 | 粗い砂・中粒・細粒・微粒 |
| カケアミ | 交差・三方向・手描き風・編み目 |
| 効果 | 集中線・スピード線・同心円・放射フラッシュ |
| 背景 | 雨・レンガ・雲・木目 |
| ホワイト | 円・四角・菱形・楕円の白インク |
| 転写 | かすれ網点・粒状・かすれ線・布目 |
| カラー | 円・四角・菱形・楕円の指定色インク |
| コピー | 元画像の輝度による円・四角・菱形・楕円網点 |

## 設定と描画

線数1–150 lpi、濃度0–100%、サイズ0.1–4倍、角度−360–360°、原稿座標のX/Y位置、インク色、白地／透明地、輝度反映、濃度反転、乱数シード0–65535を保持する。グラデーションには終了濃度と変化距離を追加する。線数の周期は `dpi / lpi` 原稿ピクセル。UIの初期線数は原稿dpiに応じて最大60 lpiとし、低解像度原稿でも初期の柄が細かすぎないようにする。

濃度0%は無描画、100%は全面。サイズ倍率は柄の閾値に作用するため、基本網点以外の「濃度」は厳密な印刷面積率ではなく濃さの制御値。円形グラデーションや集中線の中心は柄のX/Y位置で指定する。ランダム柄は整数ハッシュにより保存後も再現される。

`lumapaint-core::screentone` が設定・検証・基準描画を所有し、既存の `LayerEffects` に省略可能な設定として保存する。旧ファイルではトーンなし。新規作成はレイヤー形状とトーン設定を一度に履歴登録する。設定変更は既存のUndo／Redoとページ保存を利用する。

`lumapaint-renderer` はwgpuの既存エフェクト計算・画面直接出力へ接続する。対応するビューポートではGPUテクスチャへ直接出力する。小領域、GPUが利用できない場合、既存のタイル合成にはRust基準描画を使用する。WebViewには命令と小さな設定・状態のみを送る。大きな画像はRust／GPU側に保持する。

表示・スポイト・サムネイル・PNG等の通常文書出力・タイル文書PSD/PSB出力で原稿座標を共有する。PSD/PSBは既存の効果焼き込みの同意手順を使用し、トーンの見た目を保存する。編集可能なパラメーターはNative Formatに保持する。
