# 開発方針

## 境界

- `src`：操作画面と一時的なUI状態。Rustへの呼び出しは `bridge.ts` に集約する。
- `src-tauri`：IPC、ウィンドウ、macOSネイティブサーフェス統合。資格情報ストア・ファイル操作は後続。
- `lumapaint-core`：セッション内ドキュメントとストローク履歴。処理グラフとタイル管理は後続。TauriやReactに依存しない。
- `lumapaint-renderer`：OS非依存のwgpuレンダラーとプレビュー用WGSL。

`runtime_info`はバージョン、OS、CPUアーキテクチャを返す。
`sync_canvas`はネイティブビューと描画を更新し、実際のGPU接続状態を返す。
起動時の接続失敗とブラウザプレビューを区別する。UI翻訳は `src/i18n.ts` の型でキーを揃える。

## 次の設計判断

1. 基本描画・配置・リサイズの検証を踏まえ、ネイティブ入力、描画スレッド分離、複数画面でのRetina倍率変更を検証する。
2. ドキュメントID・ノードID・参照・スキーマバージョン・アセット所有権・保存の原子性を決める。
3. 最小のラスターレイヤーとストローク、変更タイル単位のUndo/Redoを実装する。
4. 保存・再読込・クラッシュ復旧を成立させてからAIノードに進む。

保存形式とグラフの構造は未確定のため、今回の基盤では仮の永続化モデルを導入しない。
AI生成結果は再生成に依存せず、実体と入力条件を保存する。秘密情報は作品に含めない。
モデル名と対応機能はプロバイダー単位で実装時に公式情報を確認する。

## プラットフォーム

macOSを最初の動作検証対象にする。将来のWindows（DX12/Vulkan）・Linux（Vulkan）対応を想定し、
MetalやAppKitへの依存は共有コアに入れない。macOSホストではwgpuのMetalバックエンドを使用する。
Apple Pencil等のモバイル入力はデスクトップ対応とは別に対象環境を検討する。

## 検証

`npm run build` で型検査とUIビルド、`npm run check:rust` で書式とClippy、
`npm run test:rust` でRustテストを実行する。現在は入力検査・履歴・保存・復旧・座標変換の21件を用意している（AppKit座標変換の2件はmacOSのみ）。
CIはmacOS・Windows・UbuntuでRustチェックとテストを行う。CI配置だけでは各OSの動作確認完了を意味しない。
依存関係は `package-lock.json` と `Cargo.lock` を共有する。

手動確認：デスクトップ起動時のRust接続、3言語、3外観設定、設定の再起動後保持、ウィンドウ縮小時の表示。

### ネイティブGPUプレビューの確認結果（2026-09-20）

- Apple M4 / Metalで実際のテストパターンを描画。WebViewは`tauri://localhost`。
- 100%→125%の拡大、全体表示への復帰、ライト／ダークに合わせたGPU背景変更を確認。
- ウィンドウ拡大・復元に伴い描画領域が1042×436→1042×875→1042×436pxへ変化し、再描画を確認。
- タイトルバーのSafe Area（この環境では32pt）を補正し、描画と操作パネルの重なりを解消。
- 実機画面倍率は1×。Retina 2×の数値変換は単体テストで検証し、実ディスプレイ間移動は未検証。
- UI本番ビルド、Clippy、Rustテスト5件が成功。間接依存`block`にfuture-incompatibility警告あり。
- Playwrightで1200×800・640×480・375×812を確認。ブラウザの未対応案内、3言語・外観切替、最小ウィンドウでのレイアウトを確認。
- 明示的にモックしたIPCで、拡大・全体表示・エラー時の解除・再試行・StrictMode下で同時要求数1を確認。これは実GPU故障の再現試験ではない。

### 保存機能（2026-09-20）

- v1形式でストロークとレイヤー表示状態を保存。読み込み検査はOS非依存のコアに配置。
- ファイルI/Oは上限付き読み込みと同一ディレクトリの一時ファイルによる置換。
- 保存完了後だけ保存済みにする。読み込み失敗・ダイアログ取消では既存作品を保持。
- macOSで保存済み作品の再読込とストローク数復元を確認。既存作品に干渉しない別の検証用アプリを使用。
- ウィンドウを閉じる操作と⌘Qで確認シートを表示し、キャンセル後に未保存状態と編集画面が保持されることを実機確認。
- macOSの親なし通知ダイアログは使用せず、主ウィンドウに結び付いたNSAlertシートを使用。
- 終了前にGPUサーフェスを明示的に破棄し、スレッドローカルの終了順に依存しないよう修正。
- 最終検証：Rustテスト15件、Clippy（警告をエラー扱い）、rustfmt、UIビルド、macOS .app生成が成功。

### 自動保存・復旧（2026-09-20）

- 変更確定時のスナップショットをバックグラウンドで自動保存。保存ファイルの上書きは行わない。
- 復旧コピーの選択・復旧・失敗時の再試行を3言語で実装。
- Rustテスト21件、Clippy、型検査とUIビルドが成功。
- 別識別子 `app.lumapaint.recovery-check` の検証アプリで、描画→コピー作成→対象プロセスのSIGKILL→再起動→線の復旧を確認。
- 復旧後のコピー移行と、未保存表示・自動保存完了表示を確認。
