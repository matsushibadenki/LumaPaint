# Adobe製品との機能差と実装優先度

2026-10-05時点。InDesign・Illustrator・Photoshopの全分野を対象とする。主要な制作機能をROADMAPとコードに照合した一覧であり、全コマンドの互換認証ではない。実装済みでも対応範囲を限定する。

| 分野 | 現在の実装 | 次に進める不足 |
| --- | --- | --- |
| InDesign：ページ | 単ページ／見開き、右開き／左開き、ページ管理、全ページPDF書き出し | 親ページ、余白・裁ち落とし、見開き横断オブジェクト |
| InDesign：文字・配置 | 横組み／縦組み、選択範囲の文字設定、画像フレーム、配置・リンク管理 | テキストフレーム連結、再利用可能な段落・文字スタイル、ベースライングリッド、表・目次・脚注 |
| Illustrator：ベクター | 複合パス、SVG内図形・use編集、節点、ライブコーナー、線・矢印・幅プロファイル、パスファインダー | シンボル、画像トレース、ブレンドオブジェクト、複数の塗り・線を持つアピアランス |
| Illustrator：色と出力 | スウォッチ、グラデーション、SVG／PDF書き出し、PDF互換AI読み込み | グローバルスウォッチ参照、メッシュ等の追加表現、AI固有編集情報の保持 |
| Photoshop：画素・レイヤー | タイル描画、ブラシ、消しゴム、マスク、レイヤー・フォルダUI、ピクセルグラデーション | 独立タイル形式での高度な合成・グループ保持、調整レイヤー、スマートオブジェクト、修復・コピースタンプ |
| Photoshop：ファイル | PSD／PSB RGB8部分読み込み、通常ラスターレイヤーの書き出し | 文字・効果・グループの編集情報、CMYK／16・32bit、ICC色管理、実制作ファイルによる往復評価 |

## 今回完了した工程

- [Done] 全ページPDF出力。論理ページ順とページごとの寸法・DPIを維持し、画像・フォントなどの参照IDを分離する。編集中のページと履歴を変更しない。見開きを一枚のPDFページにする機能とは区別する。
- [Done] 独立I/O層にPSD／PSBのRGB8通常ラスターレイヤー出力を追加。Unicode名、順序、表示、不透明度、RGBA画素、ロック、通常ラスターマスクを保持し、macOSの書き出しへ接続。
- [Done] 不透明度の8bit丸め、ネイティブマスク密度の画素への反映、保護設定の拡張を変換レポートと三言語確認に表示する。
- [Done] ブラシ画像出力で端タイルの行間隔を正しく扱う。右端の狭いタイルで次の行の画素がずれる不具合を修正。
- [Done] LumaPaintが生成した自作PSD／PSBをPhotoshop 2026で開き、日本語／简体中文レイヤー名、表示・ロックを画面確認。これは小規模なRGB8例の検証であり、実制作ファイル全般の保証ではない。

PSD／PSB出力は非圧縮Raw、入力タイルとマスク計64MiB、出力128MiB、最大8192pxに限定する。統合プレビューもRustで行単位に合成する。文字レイヤー・スマートオブジェクト・ICC等は現行タイルモデルに保持されないため再構築しない。PSBという拡張子への対応は超巨大画像対応を意味しない。

- [Done] PSD／PSBの水平・垂直解像度と元の表示単位を、ネイティブ保存・復旧・再出力で保持。定規と実寸表示は軸別の小数ppiを使用し、PSD固定小数点への丸めを通知。

- [Done] タイル文書とPSD／PSBに6種類の追加合成モードを保持し、同じ合成カーネルで表示・保存プレビューを作る。統合画像との比較が通る場合にレイヤーを維持する。

## 継続工程

- [Next] 組版：フレーム連結と段落スタイルを、文書モデル・再レイアウト・ネイティブ保存・IDML交換の順で実装する。
- [Next] ベクター：アピアランスと再利用オブジェクトを独立モデルへ追加し、SVG／PDFで保持可能な表現と変換を検証する。
- [Next] 画素：タイルモデルの合成モード・グループを拡張し、PSD／PSBでの階層と合成結果を往復検証する。
- [Next] 日本語の横組み・縦組み、混在サイズ、フォント置換、マスク・透明効果を含む自作サンプルをAdobe側でも比較し、差を変換レポートへ反映する。
- [Next] 複数ページSVGはページ別ファイルとしての出力仕様を設計する。現在はアクティブページのみ。
- [Later] IDML交換とINDD直接I/Oを別経路として検討。INDDとAI固有形式の完全往復は未実装。PDF互換AIのみの対応を完全AI互換と表記しない。
- [Later] 高精度画素・CMYK・ICC、プリフライト／パッケージ、表・脚注・目次、画像修復などを順次追加する。
