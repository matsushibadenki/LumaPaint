# レイヤーマスク / Layer masks / 图层蒙版

🟢 [Done] 通常文書のピクセルレイヤー／ベクターレイヤーに、ピクセルマスク／ベクターマスクを独立して割り当てられる。全4通りをサポートする。

レイヤーパネル下部の「レイヤーマスク」（◐）ボタンで設定ダイアログを開き、種類を選んで「マスクを作成」を押す。現在の選択範囲内を表示する。選択範囲がなければ原稿全体を表示する。既存マスクは「選択範囲から置き換え」で現在の設定と形状を上書きする。種類の選択だけでは既存マスクを変更しない。

マスクは有効／無効、反転、濃度0–100%、削除に対応。濃度0%は全表示、100%は指定の形状で切り抜く。元の画像・ベクターオブジェクトは変更しない。マスクの種類をレイヤーのサムネイル横に表示する。操作と説明は日本語・英語・简体中文。

- ピクセルマスク：原稿画素の中心で選択範囲を判定し、固定した二値の画素被覆を行ごとのランとして保持する。サムネイルを選択して直接描画するか、選択範囲から置き換えて編集する。
- ベクターマスク：矩形・楕円・多角形・選択ブラシの幾何と、追加／削除／交差／反転の選択操作を保持する。レンダリング時に原稿座標で判定する。サムネイルを選択して直接描画するか、選択範囲から置き換えて編集する。
- 各レイヤーには、この種類付きマスクを1つ保持する。既存ファイルの旧濃度マスク／タイルの旧マスクも保持し、存在する場合は双方の結果を合成する。グループの既存マスク操作は継続する。
- タイル文書では両種類の全面表示マスクを作成できる。既存のタイル編集UIには選択範囲がないため、通常文書と同じ選択範囲からの切り抜き操作は行わない。
