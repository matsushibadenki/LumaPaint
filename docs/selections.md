# 選択範囲

- 左のツール列の選択ボタンをクリックすると、長方形（M）・楕円形（Shift＋M）のアイコンが横に並ぶプルダウンが開く。選択中の形状を強調し、ツール名とショートカットはツールチップで確認できる。ボタンには最後に使った形状とメニューを示す三角印を表示する。ブラシへ戻った後も形状の表示を保持する。
- メニュー内は左右キーで移動、Enterで決定、Escapeまたはメニュー外のクリックでキャンセルできる。macOSではMetalキャンバスに隠れない背景・枠・影を持たないAppKitのボーダーレスウインドウを使用し、他のプラットフォームとブラウザでは同じ横並びのHTMLメニューを使用する。
- メニューの正方形ボタンはツールバーと同じ36pxの寸法・角丸・余白・SVG・選択色を使用する。macOSもツールバーのSVGと現在のCSSから生成した高解像度画像を描画し、OS標準ボタンやSF Symbolsへの置き換えは行わない。ライト／ダークの配色はアプリの設定に追従する。メニュー全体の背景・枠・影・外側余白は付けず、36pxのボタン列の中心を元のツールボタンの中心と同じ高さに揃える。macOSではWKWebViewのSafe Areaを含めて配置する。
- キャンバス内からドラッグして範囲を作る。選択範囲の外から通常ドラッグすると以前の範囲を置き換える。逆方向のドラッグにも対応する。
- Shiftを押してドラッグを開始すると加算、Optionを押して開始すると減算。両方を押した場合は減算を優先する。選択範囲内からでも加算・減算が優先される。範囲がない状態の加算は新規選択、減算は用紙全体からの減算となる。面積のない加算・減算ドラッグは変更しない。
- 修飾キーなしで選択範囲内をつかむと、離れた領域・減算した穴を含む選択範囲全体を移動する。描画済みの絵は移動しない。用紙外に移動した部分は表示・描画を用紙で切り抜く。ドラッグ中のEscは移動や範囲編集を取り消し、開始前の選択に戻す。
- Bでブラシに切り替えると、ブラシの中心位置にかかわらず描画全体を選択範囲で切り抜く。既存の描画・SVGは変更しない。
- 「選択範囲」メニューから、すべてを選択（Cmd/Ctrl＋A）、選択解除（Cmd/Ctrl＋D）、反転（Cmd/Ctrl＋Shift＋I）を実行できる。オプションバーにも解除ボタンがあり、キャンバスではEscでも解除できる。
- 選択範囲はドキュメントごとの一時的な編集状態。選択操作だけでは未保存扱いにならず、タブ切替では保持し、用紙サイズ変更・ファイル再読込では解除する。選択操作のUndo/Redoは未対応。
- 各ストロークは描画開始時の選択形状と加算・減算・反転の合成結果を保持する。後から選択範囲を移動・解除しても既存ストロークは変化せず、Undo/Redo・保存と再読込によって切り抜いた描画が復活することはない。以前の単一形状の保存データも読み込む。
- 選択形状は順序付きの領域演算として保持し、ブラシの切り抜きと点線表示が同じ形状を参照する。加算の重なり・隣接部分に内部境界を表示しない。処理量を制限するため、1つの選択は最大256領域演算とし、上限時は既存範囲を維持してエラーを表示する。
- Rustコアにプラットフォームに依存しない選択状態、wgpuに描画の切り抜きと点線表示を実装。入力は現在macOSのネイティブキャンバスに接続している。

回帰確認：`cargo test --workspace --offline`。Metal画像テスト：`cargo test -p lumapaint-renderer --offline gpu_ -- --ignored --nocapture`。硬さ0／100%、長方形／楕円、通常／反転、穴・離れた領域・移動後の描画を選択なしの画像と比較し、範囲外への漏れ・再読込後の一致・内部境界や空範囲の点線が表示されないことを検証する。

今後の対象：投げ縄、選択範囲の変形、境界のぼかし、選択内のコピー／切り取り。現在の範囲指定はブラシ描画を制限する機能。
