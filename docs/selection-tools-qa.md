## Automatic selection — 2026-10-21

The paint toolbar keeps four L-family tools and adds a W-family group: Object Selection (W), Quick Selection (Shift+W), Magic Wand (Option+W). Selection Brush has its own Option+Shift+L binding; existing bindings remain customizable. All three automatic tools expose replace/add/subtract/intersect, tolerance 0–255, and current/all-layer sampling. Magic Wand optionally searches nonadjacent matching pixels. Quick Selection uses brush diameter and seeds along the gesture; propagation follows color/alpha regions. Object Selection estimates a background from the box perimeter and expands connected foreground touched by the box. A click uses the image perimeter as the background estimate. This is color-based segmentation, not semantic object recognition.

A single Rust worker coalesces waiting jobs per window. Document identity, revision, tool and request generation reject obsolete completions; Escape and configuration/tool changes invalidate the request. Source artwork remains unchanged, and a successful result creates one selection history entry. The transparent reference excludes paper and overlays. Analysis is bounded to 1024 pixels on the longest side; larger documents have approximate boundaries. Span merging and even/odd contour bridges preserve holes and islands. Reversed GPU edges are cancelled before distance evaluation; CPU/GPU boundary tests use even/odd cancellation. Over-complex results fail without replacing the live selection (16,000 generated points; existing overall 32,768-point and 256-operation limits still apply).

UI validation: isolated production menu/settings components on localhost, 1440×1000, bundled Playwright with installed Chromium. Browser skill was unavailable. Exercised Magic Wand switching, tolerance 42, contiguous off, Quick Selection diameter 48, four L-family choices, and Japanese/English/Simplified Chinese labels. No fixture page errors; screenshot inspected. The standalone application shell requires Tauri and was not used as evidence of native canvas behavior.

Rust validation: 47 core selection-related tests, 6 renderer selection tests and 3 native host selection tests pass. Two Apple M4/Metal regressions pass: CPU/GPU clipping equality (including disconnected and degenerate polygons) and selection-outline union/subtraction behavior. ## Pixel selection menu — 2026-10-22

Implemented 18 of the 20 requested menu entries, with five Modify operations. Subject and Sky remain disabled by the user's explicit decision to implement other selection features first. No recognition model was installed. Save/load supports named masks, replacement/addition/subtraction/intersection, update, rename and deletion. Reselect is transient; saved selections persist in native document state. Layer filtering/isolation affects the layer list, not artwork visibility. Grow samples adjacent colors and Similar samples matching colors globally using current automatic-selection tolerance.

Analysis runs in a native worker on a maximum 1024px reference. Focus is a local-contrast estimate. Select and Mask has numeric smoothing, feather, contrast and boundary shift with selection/layer-mask output; it does not yet have live refinement preview, hair-edge brushing or color decontamination. Transforming inverse/stroke selections rasterizes them at 1024px; mask sampling uses nearest neighbors. These are functional approximations, not Photoshop parity. Grayscale masks remain in Rust/GPU; snapshots send their bounding summary. Quick Mask supports grayscale brush, hardness and eraser without painting artwork. Selection coverage caps completed brush opacity, including overlapping dabs.
