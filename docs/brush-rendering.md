# ブラシ描画と画像回帰テスト

ブラシは保持した入力点を曲線補間し、弧長に沿って一定間隔の円形ブラシ跡へ変換する。
GPUタイルが現在の文書・倍率と一致する間は、確定済みストロークをタイルから描き、入力中のペイントストロークだけをGPUでサンプリングする。消しゴムは従来のタイル合成経路を使う。タイル非対応の倍率では確定済みストロークのサンプルとGPUバッファを再利用し、描画結果は従来と同じ全ストローク合成を保つ。
間隔は基準半径の8%（上限は硬さに応じて1〜4 document px）。線分の境界でも間隔の残りを引き継ぎ、
最後の端数は移動距離に応じた濃度にする。入力イベント数が増えても濃度は増えない。

円形ブラシ跡の濃度は移動距離で補正し、1ストローク分の濃度を加算した後に
`alpha = 1 - exp(-density)`で透明度へ変換する。各ストロークは描画順に
premultiplied source-overで合成する。
1ストローク内の自己交差と、ペンを離して描いたストロークの交差に同じ規則が適用される。
柔らかい縁を重ねた場合は通常の透明度合成により濃くなるが、交差点を特別に検出したり、
最大値に切り替えたりしない。これにより、最大値合成によるくさび状の境界を防ぐ。

濃度の蓄積にはRGBA16Floatを使用する。色はストローク内で一定として保持し、濃度だけを加算する。
小さな透明度を逐次合成して1に近づく際の丸め誤差を避け、最後にキャンバスへ合成する。
保存形式v1へ後方互換の筆圧配列を追加し、既存ストロークもこの描画方式で再描画される。

## GPUでの検証

GPUを持たないCIでも通常のテストは実行できる。画像テストは明示的に実行する。
GPUを取得できない場合は失敗扱いとなり、成功としてスキップしない。

```sh
LUMAPAINT_GPU_ARTIFACTS=/tmp/lumapaint-brush-qa cargo test -p lumapaint-renderer gpu_brush -- --ignored --nocapture
```

本番と同じGPUパイプライン・シェーダーをオフスクリーンで実行し、出力画像を比較する。

- サイズ8・48・128px、硬さ0・50・100%で、1筆の8の字3周と、1周ずつ3回の交差領域を比較。
- 入力点の密度による直線の差と、直線の縁の周期的な濃淡を検査。
- 1筆・2筆の交差を比較し、6回重ねた場合も通常の透明度合成の数式に一致するか検査。

macOSではMetalへアクセスできる実行環境が必要。出力PNGは上記環境変数のフォルダーへ保存される。

macOSのタブレットイベントは各入力点の筆圧を0〜1で保存し、補間後の各Dabの半径へ反映する。
マウス入力と筆圧情報を持たない旧形式のストロークは筆圧1として扱う。
