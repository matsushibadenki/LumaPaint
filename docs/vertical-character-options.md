# 縦組みの欧文回転・縦中横

文字パネルで縦組みの文字を選択すると「縦組みの中の欧文回転」と「縦中横」を設定できます。編集中の選択範囲、挿入文字、文字オブジェクト全体に、既存の文字書式の経路で適用します。横書き中は設定を保持して効果を無効にします。

- 欧文回転は既定で有効です。解除するとASCII・Latin文字を正立表示し、字形の横幅に依存せず最低1 emの縦送りを確保します。英字・数字が重なる古い計測位置も同じ列の後続位置を補正します。和文は縦組みの字形を使用します。
- 縦中横は選択された同じ書式の連続文字を横組みのまとまりにします。まとまりを1 emの横幅へ字形ごと伸縮して、縦方向では1文字分を使用します。改行と書式の境界はまとまりを分けます。欧文回転より縦中横を優先します。
- 既存の計測データに縦中横の元の3文字分の送りが残っている場合は、同じ列の後続位置だけから余分な送りを除去します。前の文字・他の列・文字列・改行は保持します。補正済みのデータへ繰り返し適用しても位置を変更しません。
- RustのDocumentに書式を保存します。Undo/Redoと文書の再読込で復元し、SVGの横組み要素と`spacingAndGlyphs`を使って描画・出力へ反映します。
- AppKitのTextKit 1には縦字形属性と縦中横のキャレット用アドバンス補正を適用します。描画にはネイティブ測定の列位置・文字位置を保持し、選択中もGPU側の字形だけを表示して半透明の選択ハイライトを重ねます。アドバンス補正は既存の補正を解除してからペン位置で測り直し、編集を重ねても累積しません。実機でのIME・マウス選択と特殊フォントの組み合わせは追加検証対象です。

文字の水平・垂直比率はGPU側で字形へ適用し、TextKitには等方的なフォントと文字送りの補正を渡します。非等方的なフォント行列が縦送りを列幅まで増やす問題を避け、再計測前に補正を戻して累積を防ぎます。AppKitで垂直比率10%・50%・100%・200%の送りを実測し、横組みの垂直比率変更では横送りが変わらないことも確認しました。

文字サイズを変更した場合の最低行高・列幅は、オブジェクト作成時のサイズではなく文字書式のサイズと比率から求めます。AppKitで横組み・縦組みの40→20→80→40の変更を実測し、縮小時に元の大きい間隔が残らないことを確認しました。

ベースラインシフトはGPU/SVGの字形描画にだけ適用します。TextKitのベースライン属性はゼロとし、指定範囲のシフトが行高・列幅・後続文字の位置へ波及しないようにします。横組み・縦組みの正負のシフトで、非選択文字の画素と保存・再読込後の画像が一致することを自動検証しています。

## English

The Character panel supports **Rotate Latin in vertical text** and **Tate-chu-yoko** for selected text, typing attributes, and whole objects. Tate-chu-yoko fits a contiguous identically styled range horizontally into one em, without wrapping inside the group. Settings survive save and Undo/Redo; horizontal writing retains the settings without applying them.

## 简体中文

字符面板支持「竖排西文旋转」和「纵中横」，可应用于所选字符、新输入字符和整个文字对象。同一格式的连续纵中横字符横向缩放到一个字宽，占用一个字高，组内不换列。设置保存于文档，并支持撤销、重做和重新打开。
