# SVG / PDF I/O の準備

操作と変換処理を分離する。UIはRustから `file_format_capabilities` を取得する。
拡張子判定はダイアログの経路選択用であり、ファイル内容の検証ではない。

| 形式 | 開く | 読み込み | 書き出し |
| --- | --- | --- | --- |
| SVG | アダプターあり、メニュー接続は未完了 | macOSの既存レイヤー読み込みあり | 部分的なアダプターあり、メニュー接続は未完了 |
| PDF | 未実装 | 未実装 | 未実装 |

## 契約

- `lumapaint-formats::io::read_document` は新しいLP Document／TiledRasterStateとConversionReportを返す。開く／レイヤー追加の判断、文書ID、Undo、ファイルパスはRustホストが管理する。
- `ReadOptions` は0始まりのページ番号、ラスタ化解像度36〜2400dpi、非可逆変換の許可を保持する。SVGではページ番号0のみ有効。PDFは予約契約で、現時点では常に未実装エラーを返す。
- SVG入力はUTF-8と4MiB上限を確認する。ホストは既存のSVG検証・描画サービスによる検証を済ませてから文書を登録する。外部リソース・フォント・CSS対応を無条件に保証しない。
- 出力は既存のExportSnapshot / DocumentExporter / ConversionReportを使用する。SVGは埋め込みレイヤーを部分対応とし、非可逆変換には明示許可が必要。ブラシストローク、文書クリップ等の未対応機能はエラーになる。
- PDFアダプターは独立モジュールに置く。UI・Skia・GPUをDocument ModelやI/O契約に導入しない。ラスタ化が必要な場合はRust描画サービスへジョブを渡し、WebViewへフレームを転送しない。
- ダイアログはeditorOpen / editorImport / editorExportが有効な形式のみ通常の対応フィルターに表示する。アダプターの存在だけでメニューを有効にしない。
- 読み込み失敗・キャンセル時は現在の文書と選択を維持する。書き出しは元文書の保存状態を変更せず、変換完了後に一時ファイルから原子的に置換する。

## 実装順

- [Done] 操作別の対応表、SVG読み込み共通入口、PDF独立モジュール、ページ／dpi指定、RustからUIへの対応状況取得を準備。
- [Next] SVGの「開く」を新規未保存ドキュメントへ接続。用紙寸法・viewBox、フォント・参照リソース検証、既存文書を保持した失敗処理を実装。
- [Next] SVG書き出しダイアログ、変換警告の英語／日本語／简体中文表示、非可逆変換の選択、原子的保存を接続。
- [Next] PDFのバックエンド選定・独立アダプター実装。ページ選択、MediaBox／CropBox／回転、暗号化・パスワード、埋め込みフォント、透明度、画像とベクターの扱いを決める。
- [Later] PDFレイヤー追加・複数ページ対応、ベクター書き出し、色空間とICC、フォント埋め込み・アウトライン、互換ラウンドトリップ検証。

追加形式の準備は [追加ファイル形式の対応準備](file-format-preparation.md) を参照。
