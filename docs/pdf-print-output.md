# トンボ付きPDFの出力

[Done] 表示中のレジストレーションパスが用紙外に出ているページは、PDF書き出し時に印刷用の出力範囲へ自動拡張する。文書・履歴・ページ寸法は変更しない。通常PDF、および用紙内のレジストレーションパスだけを持つPDFは従来の用紙寸法で出力する。

- TrimBoxは元のドキュメント用紙寸法。
- BleedBoxはTrimBoxの外側3mm。
- MediaBoxとCropBoxは、裁ち落としとレジストレーションパスの範囲を含み、外周に1mmの余白を持つ。線幅・アフィン変形を含むベジェの制御点包囲範囲から保守的に算出する。
- ページ原点を移し、すべてのボックスをMediaBox内に配置する。解像度からポイントへ換算し、各ページの実寸を維持する。
- 図柄はBleedBoxでクリップする。用紙外3mmまでのベクター図柄を保持し、その外の作業領域は除く。レジストレーション線はクリップ後のページにSeparation /Allで重ねる。
- 複数ページは各ページのボックス・フォント・画像・色空間資源を保持して結合する。

ページボックスの意味は[AdobeのPDF仕様](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf)に従う。PDF/X適合や印刷用ICC変換を保証するものではない。

[Next] 任意の裁ち落とし幅・用紙範囲を指定する書き出しUI、トンボを含むページ別印刷設定。現在は3mm固定で、トンボが四角形の一部分だけを囲んでいてもTrimBoxはドキュメント全体を示す。

[Next] レイヤー効果・SVGフィルター・グレースケール合成を用紙外までラスタ化する独立スナップショット契約。現在のラスター添付は元の用紙サイズのみなので、印刷出力の拡張が必要な場合は `pdf.print_bleed_requires_vector_content` で停止し、用紙外の図柄を無言で落とさない。

登録色そのものの透明度・グループ・線効果などは引き続き基本不透明パスの対応範囲外。通常のPDF変換レポートと別に明示エラーを返す。

[Done] LPが出力する線形CMYK代替のSeparation /Allをプレビューとして読み込める。全版属性は失われるため `pdf.registration_preview_only` の損失確認が必須。任意の特色・Tint Transformや全版属性の編集モデルへの復元は未対応。
