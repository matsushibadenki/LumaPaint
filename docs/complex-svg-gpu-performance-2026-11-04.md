# 複雑SVGのGPU表示とパン

## 実装範囲

macOS／Metalの取り込みSVG表示に、Skiaで描画したGPUテクスチャをwgpuの合成へ直接渡す経路を追加した。クリッピング、単色、線形／円形グラデーション、通常の線、グループ不透明度に対応する。Rust側で解析済みSVGを描画命令へ一度だけ変換し、境界階層を持つPictureとして保持する。拡大時は画面に交差する命令を再生し、表示範囲のテクスチャだけを確保する。

命令キャッシュはスレッドごとに最大8シーン、ソースとSkiaのPicture概算容量の合計64 MiBのLRU。ソース全文の一致を確認し、変更された内容を古い命令で描画しない。入力4 MiB、正規化SVG8 MiB、表示テクスチャ32 MiBなど既存の描画制限に合わせた上限も設けた。画像データのGPU→CPU読み戻し、CPU→GPUアップロード、JavaScriptへのフレーム転送はこの表示経路にはない。

画像・テキスト・パターン・マスク・フィルター・特殊ブレンド・連鎖クリップなどは既存経路を維持する。対象は取り込みSVGの表示であり、個別編集可能なネイティブベクター／ピクセル描画／書き出しのレンダラーは変更しない。レイヤー効果が有効な場合やGPUを利用できない場合も従来の経路へ戻す。GPUだけにある画像を空のCPUキャッシュとして再利用しないこと、効果処理がコピー先として使えない共有テクスチャを再利用しないことを検証した。

UI追加や翻訳キーの変更はない。

## 比較データと条件

[前回の複雑ベクター試験](complex-vector-test-2026-11-04.md)と同じAdobeStockデータを使用した。AIの実体はEPSで直接読み込み未対応のため、前回Illustratorで保存した `/tmp/AdobeStock-1832685201-QA.svg` を両経路に入力した。2,669パス・69グラデーション・870グループ、画像要素なし。

- 元AI SHA-256: `727582ba2a6b1cbc47c752c82ec244b38a10d76291718578ea1dec5121f2f886`
- SVG SHA-256: `a2601b171a41e1bb2c69c57df0029487721de846bff0309a979215bf2fec4ab0`
- Apple M4、Metal、800×554 px、Rust testプロファイル。ビルド処理と性能測定は重ねない。

同じバイナリで既存の解析キャッシュを使うCPU描画＋アップロードと、新GPU経路を交互に実行した。両方ともGPU処理の完了まで待って測定する。画素比較用のGPU読み戻しは測定区間の後に行う。各倍率7組、初回1組をウォームアップとして除いた6組の中央値。小数座標のパンを含む。初回解析・Picture作成時間や連続入力のFPSの比較ではない。

## 描画結果

3倍率×7位置の21条件を全画素比較し、各条件でRGBA平均絶対誤差1/255未満、いずれかのチャンネル差が32を超える画素は全体の1%未満という条件を満たした。実測範囲は平均0.195〜0.718/255、大きな差のある画素の割合0.223〜0.677%。CPUとGPUで輪郭のアンチエイリアスが異なり、画素単位の完全一致ではない。最大チャンネル差は160/255であり、この最大値を隠して「完全に同じ」とは扱わない。

各倍率の中央位置では、差32超の画素は全体表示3,002個、200%で2,703個、400%で1,171個。CPU画像の3×3近傍内に16/255超の変動がある場所を輪郭近傍とすると、その外にある該当画素はそれぞれ1個・0個・0個だった。この追加監査はPNGから前乗算RGBAを復元した値であり、直接RGBAの比較とは丸めが異なる。

比較PNGとTauriで花柄の重なり、切り抜き形状、線とグラデーションの維持を目視確認した。別の小さな回帰データでは、クリップ、半透明グラデーション、重なる半透明グループ、レイヤー不透明度、座標変更、同じ長さのソース変更、アートボード外表示、GPU／CPU経路切り替え、効果変更とUndo／Redoを検証した。

## Tauri実機

更新したdebugバンドルを起動し、元SVGを新規文書として開いて測定。元データのまま200%／400%で80×50画面ポイントのパンを3往復ずつ実行した。各倍率6フレーム。過去の検証文書にあった変形の影響を避けるため、最終記録には新規読み込み文書の測定だけを採用した。

| 倍率 | 前回CPU経路のホスト中央値 | 今回GPU経路のホスト中央値 | 今回の最大値 |
| --- | ---: | ---: | ---: |
| 200% | 148.415 ms | 8.190 ms | 10.50 ms |
| 400% | 252.315 ms | 5.360 ms | 9.17 ms |

全12フレームでGPU描画各1回、描画命令キャッシュヒット各1回、SVG再解析0回、CPUによるSVGラスタライズ0回、SVG表示画像のアップロード0 bytesを確認した。表示範囲のGPUテクスチャは1,772,800 bytes。これは`render_canvas`のホスト処理時間で、上のGPU完了時間の測定とは異なる。入力から物理表示までの遅延やFPSには換算しない。

追加でレイヤーの半透明表示、効果の適用／解除、露光量0↔0.7のUndo／Redo、レイヤー表示／非表示、他の文書への切り替え後の復帰を確認した。効果が有効な場合は互換経路へ戻り、解除後はGPU経路に復帰する。

元SVGだけを読み込んで拡大・パンした確認文書を `/tmp/AdobeStock-Complex-GPU-Original-QA.lumapaint` に保存。保存されたSVG全文と元SVGの完全一致、元AI・SVGのハッシュ不変も確認した。元のストックデータ、変換SVG、プレビュー画像はリポジトリに含めない。
