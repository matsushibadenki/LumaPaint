# モーションとタイムライン — 2026-10-12

[参照サイト](https://motion-reference.takayustudio.jp/)の実際の統合カタログ、公開デモの変形・キーフレーム、SVG演出、文字演出を調査し、64カテゴリ・782項目を作品に適用できるプリセットとして登録した。[項目別の実装一覧](motion-reference-coverage-2026-10-12.md)にID、初期時間、カーブ、合成する動き、複数要素のトラック数を記録する。

## 使用方法

1. 編集可能なベクターまたは文字のレイヤーを選ぶ。
2. プロパティの「モーション」を開き、タイプを検索またはカテゴリで絞る。
3. 開始・長さ・移動量・支点・遅延幅などを調整し「追加」する。文字の置換、数字、粒子、ぼかし、複製数、経路、モーフ先などは該当するタイプで表示する。
4. フレームを移動または再生して確認する。「クリップ」で有効／無効、並べ替え、複製、削除を操作する。変更は「適用」で保存され、Undo/Redoに対応する。
5. 下部タイムラインにはクリップの範囲が表示される。ドラッグして開始時刻を移動できる。モーションパネルは既存のドッキング／フローティング機構で配置を変更できる。

開始はUIで1始まり、保存データは0始まり。長さはフレーム数。クリップを追加すると必要な長さまでタイムラインを同じUndo単位で延長する。削除や短縮でタイムライン全体を自動短縮しない。複数オブジェクトの反応は登録順に割り当て、対象を選択オブジェクトにすると保存したID順を使用する。

英語・日本語・简体中文に対応。動きの説明は各タイプの情報アイコンから表示する。

## 実装

- RustのDocument/Animation/Trackがクリップとパラメータを所有する。WebViewは命令、カタログ、タイムライン状態だけを扱う。フレーム画像をIPCで送らない。
- 元の作画とプレビューを分離し、保存したシードとフレーム時刻から同じ描画を再現する。再生時刻はRustのInstantを使用する。既存のコマ撮り・キーフレームも維持する。
- 17系統のカーブと83種類の動きの要素を合成する。185項目は押下、保持、反動などの複数要素の数値トラックを持つ。単一の作品オブジェクトでは、複数要素のデモ全体のうち対応する要素が動く。
- 図形の変形はRustで座標を更新する。マスク、光、色、歪み、粒子はRustで生成した描画ソースを既存のSkia/resvg/wgpu描画経路で処理する。文字はUnicodeの書記素単位で遅延させ、スタイル範囲はUTF-16境界を維持する。
- 文字の線描画にはネイティブ字形のアウトラインを利用する。キャッシュは64項目・8 MiBまで。ビットマップ絵文字など輪郭化できない字形は通常の文字描画を維持する。
- モーフ先のSVGパスを指定すると、輪郭ごとの弧長対応で形状間を補間する。輪郭数の異なる対象や編集可能なパス以外はエラーにする。未指定では柔らかな形状変形を使用する。
- 残像と放射状の複製はソースを1つ保持した参照描画にする。コピーの展開積はレイヤーごとに125まで。クリップは64／レイヤー・512／ドキュメント、パラメータは合計2 MiB、生成SVGはレイヤーごとに4 MiBまで。過大な旧データでは元のSVGを保持する。長い文章は、文字ごとのソース複製を避けてスタイル範囲の描画に戻す。
- 編集要求にドキュメントIDを付け、切り替え後の古い要求を拒否する。再生・停止・シークは同じウインドウのタイムラインパネルに通知する。

## 対応範囲と制約

782項目へのタイムライン適用と参照サイトの全デモの完全な再現は別である。現在は選んだ作品の形状・文字に動きを適用するため、サイトのボタン、ゲームHUD、グラフなどの専用アートワークやUI構造を自動生成しない。

- ホバー、ポインター、スクロール、ジェスチャー、フォーム反応は時間軸に沿って再生する。実操作へのイベント連動は今回の優先範囲に含めない。
- 立方体・板・円筒のメッシュと透視投影、深度、照明をRust/wgpuで描画する。3D文字の層は板を積んだ形状で、字形の側面をつなぐ押し出しメッシュは未実装。フィルター・文書クリッピング・予算超過時はSVG互換描画に戻り、三角形ごとのアフィン補間になる。
- 可変フォントの実軸を駆動する。Roboto FlexとNoto Sans JPを同梱し、選択フォントの対応軸と範囲を検証する。日本語の幅・傾斜はフォントが対応する場合に限る。通常の文字編集パネルのフォント一覧にはモーション専用名を表示しない。
- 漢字筆順はKanjiVGの6,626字の中心線データを使う。日本語の標準筆順であり、简体中文の筆順体系を網羅しない。未収録字・異体字指定は拒否する。筆順字形は選択フォントの輪郭とは異なる。筆圧の実測データは含まない。
- 音に同期するタイプは設定した周期で動く。音声のビート検出、音量解析、音源への自動同期は未実装。
- 保持SVGやクリッピンググループはレイヤー全体の動きに対応。部分対象や文字の組版変更は編集可能な作画を使用する。

## 検証

macOS / Apple M4 / Metalで、ネイティブアプリの図形作成、クリップ追加、長さ変更、中間フレーム描画、再生、作品への保存、フローティングへの切り離しを確認した。保存したJSONにクリップと全パラメータ、元の図形が残ることも確認した。

ブラウザーで実コンポーネントと検証用transportを使い、日本語・英語・简体中文、240pxのパネル幅、検索、追加、スプリング減衰変更、適用、複製、モーフ先入力を確認した。横幅238pxの内容に対してscrollWidthも238pxで、入力やボタンの横方向のはみ出しはなかった。これはUI検証であり、Rustの描画をブラウザーで模擬したものではない。

- 全コアテスト：338 passed / 1 ignored。
- モーション固有のコアテスト：カタログの全IDと3言語、数値範囲、決定的なSVG生成、時間端点、反復、対象、支点、シード、Unicode、Undo、コピー制限、モーフ先補間と不正入力。
- Skia描画テスト：782項目を開始・短い反応中・中間・終了の4時刻で描画し、各項目に時間による画像変化があることを確認。マスクの空／途中／完成、文字輪郭の可視性、保存・復元後のピクセル一致も確認。
- ネイティブ側の全テスト：180 passed / 1 ignored。追加した古いモーション要求・パネル終了要求のドキュメントID検証も1件成功。
- TypeScript、フロントエンド本番ビルド、core/formats/renderer境界検査、対象Rustパッケージの全ターゲットClippy（警告をエラーとして扱う）に成功。既存のメインJSチャンクには500 kB超のビルド警告が残る。モーションパネル自体は遅延ロードする。

描画成功はサイトとのピクセル同一性や全項目の60fpsを保証しない。Windows/Linuxの実機操作と、大規模な作品に全モーションを適用したRelease性能は別の検証が必要。
