# Roadmap

- [Done] 変形パネル：9点の基準点、X/Y、W/H、縦横比固定、回転・シアーの絶対値入力とプリセット、mm/cm/in/px/pt表示。長方形の寸法・回転と4隅の角半径を個別／連動編集し、角・線幅と効果の拡大縮小設定、Undo/Redo、保存・再編集、英語・日本語・简体中文に対応。入力途中は更新せず確定時にRustのDocument Modelへ反映。

表記：`[Done]` 現在のコードに実装済み / `[Next]` 優先度の高い未完了作業 / `[Later]` 後続の計画 / `[Pending]` 保留中。
macOSを優先する。macOS以外の未完了作業は`[Pending]`とし、再開指示があるまで着手しない。既存の共通コードやCIの`[Done]`は実装済みの事実を示す。

## 開発基盤

- [Done] WebviewWindowによるマルチウインドウ。「ウインドウ → 新規ウインドウ」／Cmd・Ctrl+Shift+Nで空の編集ウインドウを追加。Rust側でドキュメント・タブ・履歴・選択・文字編集・画像配置・描画面・ズームを個別管理し、IPCとネイティブ入力・描画ワーカーの結果を対象ウインドウへ振り分ける。描画キューは各キャンバスの最新要求を保持し、ウインドウ間では公平に処理。個別閉鎖と全体終了の未保存確認を分離。自動保存はプロファイルのロックを共有し、ウインドウごとに復旧コピーを保持して次回起動時にまとめて検出。
- [Done] 親ウインドウ付きのモーダルWebviewWindow。新規ドキュメント・設定・カラー設定・変形・節点編集・画像読み込みを専用画面へ分離。macOSはネイティブシート、他OSは親の入力を無効化して表示。親のRustセッションへ命令を送り、変更通知・確定・キャンセル・処理中の閉鎖保護を統一。他の編集ウインドウは操作を継続できる。
- [Later] ウインドウ間へのドキュメントタブ移動・同一ドキュメントの複数ビュー。

- [Done] 起動時は新規ドキュメントダイアログを自動表示せず、ドキュメント未作成の空のワークスペースを表示。新規作成はメニュー・ショートカットから開く。
- [Done] 起動時の右側パネルはレイヤーパネルを選択。前回のテキストパネル選択状態は復元せず、操作によるパネル切り替えは維持。
- [Done] ツールメニューのテキストフレームを横書き用・縦書き用に分離。選択した組み方向で新規枠を作成し、既存枠の編集・枠サイズ変更も両ツールで対応。英語・日本語・简体中文のラベルを追加。
- [Done] 文字ツールも横書き用・縦書き用に分離。クリックで選択した組み方向の文字を作成し、既存文字の編集時は元の組み方向を維持。3言語のラベルと縦書き用アイコンを追加。
- [Done] 横書き・縦書き文字ツールを固定枠のないポイント文字へ変更。自動折り返しをせず、選択時は実測範囲のバウンディングボックスとベースライン、編集中はガイドを消して選択文字を黒地・白文字で表示。テキストフレームは固定枠を維持。縦書きフレームのクリック作成は縦型、ドラッグ作成は指定寸法を維持。
- [Done] ポイント文字の横組み／縦組み切り替え時に先頭文字の開始位置を保持。縦組みの座標基準を1列幅に正規化し、文字・オブジェクトの拡大縮小と回転を考慮して位置を補正。Undo/Redoで復元。
- [Done] ピンチ倍率の通知とUIの倍率変更命令を分離。遅れたUI同期による倍率の巻き戻りを防ぎ、拡大縮小の描画要求を画面更新単位でまとめる。
- [Done] テキストパネルの数値確定時は文字配置の再計測とGPU再描画を完了してから応答し、AppKitの選択表示も更新。
- [Done] 文字選択後に数値欄へフォーカスを移しても、選択背景を半透明で描画。不透明なグレーでGPUの文字プレビューを覆わず、サイズ入力中も実際の文字を確認できる。
- [Done] 文字パネルの数値入力中は入力欄だけを更新し、Enter／フォーカス移動で確定してから文字計測・描画を更新。Escは取消、無効値は元の値へ戻す。
- [Done] 文字の縦横倍率・回転を文字範囲の書式へ追加し、選択した部分だけに適用。選択外の書式・枠の倍率は維持し、保存／SVG描画／文字配置の計測に対応。旧形式の文字書式は倍率100%・回転0として読み込む。
- [Done] macOSの文字・図形キャッシュ生成をSkia Metal優先に変更。GPU初期化・描画サーフェス確保・画素読み戻しの失敗はCPUへ自動切替し、未対応SVGは互換CPU経路を維持。GPUコンテキストをスレッドごとに再利用。

- [Next] Skia Metalとwgpu間のテクスチャ共有で、GPUキャッシュ生成後の読み戻し・再転送を削減。
- [Done] Tauri 2 + React + TypeScript + Viteの起動構成
- [Done] UIから独立したRustコアのワークスペース
- [Done] Rustコアとの読み取り専用IPCと接続状態表示
- [Done] 英語・日本語・简体中文のUI

## 大規模Sceneとキャッシュ（[設計・合格条件](large-scene-rendering.md)）

100万件を毎フレーム処理せず、変更・表示対象だけを扱う方針を採用。60／120fpsは未達成の実機目標で、現在のv1容量上限は維持する。

- [Done] 既存ペイントタイル、SVGレイヤーGPUキャッシュ、文字フレームCPUキャッシュ、最新要求優先のワーカーを大規模Sceneへの移行基盤として整理。
- [Done] 文字フレームキャッシュの診断へ件数・計上ペイロード・予算・追い出し数を追加。全メモリ／VRAMの計測とは区別。
- [Done] テキスト入力・サイズ変更中の同期プレビューにも文字フレームキャッシュを接続。単独ボックスも対象にし、用紙全体に描画してから切り抜く処理を描画bounds内の小さなSurfaceへ置換。三言語・変換・線・クリップ・効果のフル描画一致、キャッシュ再利用と大きな用紙での小Surface化を検証。
- [Next] オブジェクト変更Journalとgeometry／transform／style等の個別世代を導入。編集・Undo/Redo・削除・読込を接続し、全SVG比較・全量生成を更新対象だけへ置換。静止と1個移動で計測。
- [Next] 描画boundsとBVHによる可視判定・選択候補抽出。線・矢印・効果と描画順を維持し、線形探索との一致と検査ノード数を検証。
- [Later] 共有ページのScene Compilerとimmutable RenderSnapshot。変更ページだけを更新し、版の公開・古いワーカー結果の拒否・入力遅延を検証。
- [Later] Vector Tile／Group／EffectキャッシュとCPU／GPUの共通予算。Dirtyタイルの全寄与要素を正しい順で再合成し、半透明・クリップ・ぼかし継ぎ目を検証。
- [Later] 画面誤差で選ぶLOD／Mip、描画スレッド分離、Animationの変更ノードだけの更新。
- [Later] 新容量契約で10万／100万件の読込・保存・履歴・編集を実機測定。p95／p99、転送量、メモリ、deadline超過を記録してから容量上限と性能表記を更新。

## 最初の制作機能

- [Done] 移動・ビュー変更と文字組み変更の更新を分離。文字入力・書式変更の計測／通知をフレームへ集約し、パン・ズーム・表示クリップの変更だけでは文字組みキャッシュを無効化しない。ドラッグ／パンの中間描画は最新状態へ集約し、確定は同期反映。macOS 14以降はViewに紐付くDisplay Link、旧OSはAppKitのレイヤー更新を使用。アイドル時は停止し、View交換時はリンクを破棄。実機で2000要求→2フレームと停止・再開を検証（アプリの長文FPSは未計測）。
- [Done] テキストのバウンディングハンドルは通常ドラッグで文字サイズ・変形倍率を維持して枠だけ変更。⌘ドラッグ時は文字を含む拡大縮小を実行。回転・既存のアフィン変形を考慮した枠座標でリサイズし、横組みの幅・縦組みの高さ変更時は折り返しを再計算。通常リサイズの書式維持と⌘変形の確定・Undo/Redoを検証。
- [Done] ベクター選択のクリック判定を読み取り専用にし、文書・Undo履歴の丸ごとの複製を廃止。複数の描画区間を持つレイヤーも選択解除時はGPU画像を再生成せず、選択フラグだけを更新。
- [Done] 通常の文字・図形を描画範囲のGPU画像として保持し、同じ画像をアートボード内外に表示。ドラッグ中は位置のuniformだけ更新し、文字組み・SVG再生成・画像転送を省略。確定した平行移動とUndo/Redoは16バイトの描画矩形更新で画像を再利用。混在選択は描画順の連続区間に分けて合成し、依存クリップ・非標準合成・予算超過は従来経路へフォールバック。追加画像は合計64MiB、最大64区間・8192px。Metalで半透明画像の境界横断と画像再転送なしを検証（長文の実操作FPSは未計測）。
- [Done] アートボード外のベクター・文字・読み込みSVGを作業領域に表示。レイヤー順・不透明度、移動プレビュー、選択枠、文字編集に対応し、パネルへのはみ出しを防止。用紙寸法・保存・書き出し範囲は維持。外側描画は表示範囲のキャッシュを再利用し、追加画像の合計を64MiBに制限（多数レイヤー時は解像度を調整）。ピクセルのブラシ描画は引き続き用紙内。
- [Done] 混在した文字サイズに合わせてネイティブ文字組みの行・列の高さを自動拡張し、縦書きで拡大文字が隣の列と重なる固定高さを解消。長文のドラッグ選択中は全文のパネル通知を抑制し、終了時に同期。書式属性の一括変更をまとめて適用。縦書きの枠超過部分も計測して位置情報の全破棄を防ぎ、列中心を最大サイズを含む実際の列幅から算出。AppKitで100列の混在サイズ・枠超過レイアウト・列間の非重複を検証（アプリでの長文ドラッグ操作の追検証は未実施）。末尾改行の空段落をextraLineFragmentとして計測し、行数不一致による全位置情報の破棄を防止。横組みの枠超過も全体計測し、三言語・空行・混在サイズ・末尾改行のAppKit検証を追加。
- [Done] テキスト編集の選択色をキャンバスの表示領域でクリップ。拡大・パン時の文字座標を維持し、右側パネル・ツールバー・ステータスバーへのはみ出しを防止。ネイティブViewとCore Animationの両方でクリップを適用。

- [Done] ペイント用ブラシ・インクペンの距離ベースADSR減衰エンベロープ。立ち上がり／減衰／持続距離／消え際・持続濃度・かすれ量、ドラッグ可能なカーブ図と数値・スライダー、ストロークへの保存・旧形式互換・Undo/Redoに対応。Rustの共通サンプラーでGPU／タイル描画へ適用し、消しゴムから分離
